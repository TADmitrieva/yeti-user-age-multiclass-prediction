# yeti-user-age-multiclass-prediction
Разработка модели многоклассовой классификации для предсказания возраста интернет-пользователей по "цифровому следу"

## Краткое описание проекта

Данный проект посвящен разработке сквозного автоматизированного пайплайна машинного обучения для задачи **многоклассовой классификации пользователей по 5 возрастным категориям**. В качестве исходных данных выступает цифровой след клиентов (покликовые логи посещения сайтов), а также их технические и сервисные характеристики. 

Основная бизнес-цель проекта — предоставить маркетинговой команде «Йети» точный инструмент сегментации аудитории для таргетинга рекламных кампаний. Дополнительный критический фокус бизнес-задачи — минимизация юридических и комплаенс-рисков путем исключения показа рекламы категории "18+" несовершеннолетним пользователям.

---

## Архитектура и этапы реализации проекта

Проект реализован в виде монолитного, защищенного от утечек данных конвейера (`Pipeline`) библиотеки `scikit-learn` и включает следующие этапы:

1. **Исследовательский анализ данных (EDA):** Анализ распределения целевой переменной, выявивший сильный многоклассовый дисбаланс (максимальный класс — 30.31%, минимальный — 8.82%).
2. **Аналитическое конструирование признаков (Feature Engineering):** Сырые логи сессий агрегированы на уровне профилей пользователей. Рассчитаны высокоинформативные непрерывные предикторы — точные процентные доли активности клиента по 4 периодам времени суток и 20 тематическим категориям веб-ресурсов.
3. **Предобработка данных (ColumnTransformer):** Автоматическая обработка пропусков (`SimpleImputer`), масштабирование числовых долей (`StandardScaler`) и прямое кодирование категориальных признаков (`OneHotEncoder`).
4. **Автоматический отбор признаков (Feature Selection):** Инкапсулированный внутрь пайплайна селектор `SelectKBest` на основе критерия взаимной информации (`mutual_info_classif`) выполнил фильтрацию избыточного OHE-шума, зафиксировав ядро из **50 наиболее информативных компонентов**.
5. **Тонкая настройка (Hyperparameter Tuning):** С помощью `GridSearchCV` оптимизирована сила L2-регуляризации (параметр `C=1.0`) многоклассовой логистической регрессии.

## Результаты и метрики качества

Благодаря учету многоклассового дисбаланса, основным критерием оценки качества выступает макро-усредненная метрика **F1-macro**:

* **Результат на кросс-валидации (Train):** `F1-macro = 0.8266`
* **Результат на отложенной выборке (Test):** `F1-macro = 0.81` (Общая точность `Accuracy = 0.84`)

> **Выполнение требований ТЗ:** Разработанное решение значительно превзошло установленный заказчиком критический нормативный порог эффективности (**не менее 0.75**) как на этапе обучения (0,8266), так и на независимом тестировании (0,8118), и полностью готово к внедрению в промышленную эксплуатацию.

### Ключевые аналитические инсайты (по матрице ошибок):
* **Максимальная точность:** Модель идеально распознает старшую возрастную группу (класс 4, `F1-score = 0.89`), поведенческий паттерн которой наиболее специфичен.
* **Защита комплаенса:** Ошибки, при которых несовершеннолетний пользователь (класс 0) ложно классифицируется как взрослый, сведены к минимуму, что полностью решает задачу снижения рисков показа запрещенной рекламы подросткам.

## Инструкция по локальному запуску

Для развертывания проекта и запуска финального блокнота выполните следующие шаги в вашем терминале:

1. **Клонируйте репозиторий:**
   ```bash
   git clone github.com
   cd yeti-user-age-multiclass-prediction
   ```

2. **Разверните виртуальное окружение и установите строго зафиксированные зависимости:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Запустите Jupyter Notebook и откройте файл исследования из папки notebooks:
   ```bash
   jupyter notebook notebooks/yeti_age_prediction.ipynb
   ```

## Содержимое репозитория
* `yeti_age_prediction.ipynb` — финальный рабочий блокнот с исследованием и кодом.
* `requirements.txt` — файл со строго зафиксированными версиями библиотек (включая `scikit-learn==1.3.2` для устранения конфликтов OHE).
* `final_multiclass_pipeline.joblib` — сериализованный готовый к деплою монолитный пайплайн модели.
* `data_processing_util.py` — утилитарный скрипт с функцией склейки исходных таблиц.
